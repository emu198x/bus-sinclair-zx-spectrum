# bus-sinclair-zx-spectrum

The ZX Spectrum family's wiring: the Ula, MemoryBus, Peripheral and MemoryIntercept traits and the FrameTiming data.

| Crate | Registry |
|---|---|
| [`emu198x-bus-sinclair-zx-spectrum`](crates/emu198x-bus-sinclair-zx-spectrum) | [crates.io](https://crates.io/crates/emu198x-bus-sinclair-zx-spectrum) |

Part of [Emu198x](https://github.com/emu198x/emu198x), a family of
cycle-accurate retro-computing emulators. Implemented by the Spectrum-family ULAs and edge-connector peripherals, and called by the Spectrum, Timex, Pentagon and Scorpion machines.

Each crate is versioned on its own and bumps only when it changes. Releases go
through release-plz: merging its release pull request tags the crate and
publishes it.
